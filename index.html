HTML چیست؟ آموزش HTML برای مبتدی‌ها

HTML مخفف HyperText Markup Language است و پایه تمام صفحات وب است.

<html>
  <body>
    <h1>سلام دنیا</h1>
    <p>این اولین صفحه HTML من است</p>
  </body>
</html>

نکته: HTML بدون CSS ظاهر ساده دارد. برای زیبایی صفحات باید CSS استفاده شود.
